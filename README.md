## 🛠️ Troubleshooting

Sometimes things don't work perfectly on the first try. Here are common problems and their fixes:

### 🔌 Can't Access the Web Interface

- Make sure your computer and PS5 are on the **same network** (same Wi-Fi or same router)
- Check that the PS5 is fully on, not in rest mode
- Try refreshing the browser page a few times
- Reboot both your PS5 and your computer, then try again

### 📡 Updates Not Appearing

- Ensure your internet connection is stable on the PS5
- Close the web interface and reopen it after a minute
- Try the "Refresh" button on the dashboard

### 🔁 Payload Doesn't Start

- Double-check that the file transferred correctly to your USB drive
- Make sure the USB drive is formatted as FAT32 or exFAT
- Try a different USB port on the PS5

### 🌐 Web Page Looks Wrong

- Use a modern browser (Chrome, Edge, Firefox, or Safari)
- Clear your browser's cache and reload
- Try using a different device (like your phone) instead
